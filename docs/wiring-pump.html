1. Overview

The syringe pump uses the Mega's second hardware serial port, Serial1. The scale uses Serial2. Each device has a dedicated RS485 adapter and a separate bus, avoiding address conflicts and isolating communication faults.

The pump's 24V power is separate from the Arduino's 5V supply, with a common signal reference at pin 10. Separate power branches reduce startup disturbances.

Identifying A and B

MethodProcedure
1. Read the labelsCheck printed wire markings and the factory cable color chart.
2. Continuity test (preferred) Disconnect the cable from the pump with power off. Use continuity mode and a suitable fine probe at DB15 pin 11. Test the three conductors in the first bundle: the conductor with continuity is A. Repeat at pin 12 to identify B.
3. Voltage measurement With the pump powered at 24V and idle, the documented auxiliary outputs are near 0V, while A and B may show different bias voltages around 1–3V. Use this only as supporting evidence.
RS485 A/B labeling can differ by manufacturer. If communication fails after checking the wiring, power down and reverse only the identified A and B signal leads, then test again.

8. Converting Volume to Steps

The ASCII (DT) protocol uses half-steps with 12000 steps per full stroke. The backend module backend/functions/pump.py converts the volume selected in the console:

steps = volume (µL) × 12000 ÷ syringe capacity (µL)
raw speed = flow (mL/s) × 12000 ÷ syringe capacity (mL)
Syringe capacityVolume per stepMaximum speed (raw value 6000)
5 mL0.4167 µL / step2.5 mL/s
2.5 mL0.2083 µL / step1.25 mL/s
1.25 mL0.1042 µL / step0.625 mL/s
500 µL0.0417 µL / step0.25 mL/s
250 µL0.0208 µL / step0.125 mL/s
Syringe capacities are defined in config/hardware.yaml under syringe_pump.syringe_options_ul. The console generates capacity buttons from this list. After changing the configuration, restart the backend; no code change is required.

10. Troubleshooting

SymptomChecks
Detect receives no response
The log shows ERR,pump_timeout		 ① Check A/B polarity and retry after correcting the identified signal pair with power off.
② DI, RO must match D18→DI and D19→RO.
③ Check the 24V supply and pump display.
④ Check signal ground (⑦).
⑤ A DE/RE adapter requires firmware changes; see Section 3.
Only transmitted data is echoed backCheck adapter direction control. This installation requires an automatic-direction adapter.
Unreadable responseCheck the baud rate. The pump default is 9600; restore it through the pump panel if changed.
error=7 Device not initializedSelect Initialize
error=9 Plunger overloadCheck for blocked tubing or excessive speed. Reduce to 0.1 mL/s, clear the obstruction, then initialize again.
error=10 Valve overloadCheck for a stuck valve. Resend the valve-position command to rehome it; repeated faults require valve inspection or replacement.
error=2 / 3Parameter out of range, such as a step count exceeding the full stroke.
Incomplete homingCheck the homing stall-current setting for the syringe: 25 µL→4, 50 µL–1.25 mL→5, 2.5/5 mL→6.
Brief command delay while stepper motors runThe firmware services stepper pulses while waiting for pump responses. Serial handling can still delay command completion.
Backend command timeoutClose the Arduino IDE Serial Monitor if it is open. Only one process can open a COM port at a time.

Connection Checklist

  • The adapter uses automatic direction(no DE/RE connection).
  • D18 → DI, D19 → RO(correct orientation)
  • Adapter VCC → 5V and GND → GND, subject to the adapter voltage rating.
  • A → pin 11, B → pin 12, GND → pin 10
  • 24V: +V → pin 1 and −V → pin 9, on a separate branch from the DM542J.
  • The DB15 was wired using the solder-face view and checked for continuity.
  • The syringe pump uses Serial1 and a dedicated adapter; the scale uses Serial2 and a separate adapter.
